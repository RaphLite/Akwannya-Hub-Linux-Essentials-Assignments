# **Cisco Linux Essentials — Learning Journey**

## **About This Project**

This repository documents my learning journey through the Linux Essentials course with Akwannya Hub, delivered through Cisco Networking Academy.

My goal is to build a solid understanding of the Linux operating system, develop practical command-line skills, and explore how Linux supports modern IT infrastructure.

##** Learning Objectives**

Throughout this course, I aim to:

- Understand Linux fundamentals and open-source software.
- Navigate the Linux command line and filesystem.
- Manage files, directories, and text.
- Explore basic scripting and automation.
- Understand computer hardware, storage, and networking.
- Learn the fundamentals of Linux security, users, groups, and permissions.

## **Documentation Structure**

Each module will include a summary of the topics covered, key concepts, practical exercises, important commands where applicable, and personal reflections on what I learned.

## **Why I'm Learning Linux**

I'm building my technical foundation to better understand the systems, tools, and infrastructure behind modern technology, particularly in cloud computing and technical support.

This repository will serve as a record of my progress, practical learning, and continuous improvement.
